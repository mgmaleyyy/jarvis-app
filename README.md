# J.A.R.V.I.S.

Osobní desktop asistent (Python + webové UI v okně Edge/Chrome).

| Edice | Složka | Výstup |
|---|---|---|
| J.A.R.V.I.S. (pro kamarády) | `home/` | `JARVIS-Setup.exe` (Windows) |
| J.A.R.V.I.S. Executive | `exec/` | `JARVIS-Executive-Setup.exe` (Windows), `JARVIS-Executive-Mac.zip` (macOS) |

Sestavení běží automaticky v GitHub Actions (PyInstaller + Inno Setup).
Hotové instalačky: záložka **Actions** → poslední běh → **Artifacts**.
Verze ke stažení pro ostatní: vytvoř tag `v1.0.0` → objeví se v **Releases**.
